#IT Solution operations Manager

## Description
A simple Java console application for managing IT support operations with a basic ticketing system.

## Features
- Create a new support ticket
- View all existing tickets
- Resolve open tickets

## How to Run
1. Compile the Java file:

javac src/ITSolutionOperations.java

2. Run the compiled program:

java -cp src ITSolutionOperations

## Requirements
- Java 8 or newer
- No external dependencies
